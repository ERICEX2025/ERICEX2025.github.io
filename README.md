## Local Development

Requires Ruby (installed via Homebrew):

```bash
bundle install
bundle exec jekyll serve
```

Open http://127.0.0.1:4000/ to preview. The server auto-regenerates on file changes.

> **Note:** Don't open HTML files directly in the browser — Jekyll needs to process the layouts and templates first.
